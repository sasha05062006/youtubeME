# YouTubeME — запуск на Windows 11

## Что это

YouTubeME — бесплатный экспериментальный конвейер для сборки короткого 3D-мультфильма: сцены Blender, русская озвучка Piper, музыка, фоновые звуки и итоговый MP4. Это ещё не студийный уровень: модели персонажей простые, а голоса синтетические. Полный рендер на слабом ноутбуке может идти очень долго.

## Первый запуск

1. Открой репозиторий: https://github.com/sasha05062006/youtubeME
2. Нажми **Code → Download ZIP**, распакуй архив в обычную папку, например `C:\YouTubeME`. Не запускай проект прямо из ZIP.
3. Убедись, что на диске есть несколько гигабайт свободного места и работает интернет.
4. Дважды нажми `FIRST_RUN.bat`. Скрипт установит Blender, FFmpeg, Python-окружение и две русские офлайн-модели голоса. Если Windows спросит подтверждение установки, подтверди.
5. Когда скрипт завершится, закрой его и открой заново окно терминала/проводника, чтобы Windows обновила PATH.
6. Запусти `create_cartoon.bat`, опиши сюжет и введи длительность в секундах. Для первого теста начни с **15–30 секунд**, а не с трёх минут.
7. Готовое видео и JSON-отчёт ищи в `output\ready\`. Если проверка качества не прошла, результат будет в `output\quarantine\`; изучи текст ошибки в `output\work\cartoon_...\error.txt`.

## Важное ограничение автономного режима

По умолчанию отдельная языковая модель не нужна, но встроенный планировщик пока использует готовый сценарий про слонёнка и друзей, подстраивает длительность и название. Он **не переписывает всю историю с нуля под любое описание**. Для полноценного свободного сочинения нужен дополнительный локальный ИИ, которого этот репозиторий автоматически не устанавливает.

## Если запуск не удался

- Blender или FFmpeg не найдены: закрой и заново открой терминал; если не помогло, установи их вручную и проверь, что команды `blender`, `ffmpeg` и `ffprobe` доступны в PATH.
- Не найдены голоса/Piper: повторно запусти `install_russian_voice.bat`.
- Не скачались звуковые эффекты: проверь интернет и запусти `install_audio_assets.bat`, затем повтори создание.
- Не публикуй MP4 автоматически: перед публикацией просмотри видео и прослушай звук.

## Честный статус

GitHub Actions проверяет синтаксис Python и тесты сценария/аудиотаймлайна. Полный рендер Blender + Piper + FFmpeg ещё не проверен на конкретном ноутбуке, поэтому обещать, что первая трёхминутная сборка пройдёт без ошибок, нельзя.
