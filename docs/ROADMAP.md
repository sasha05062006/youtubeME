# Roadmap

## MVP in this repository

- [x] Free, local-first orchestration with no paid API dependency
- [x] Procedural 3D character, props, environment, camera, lights, and keyframed animation
- [x] Vertical H.264 MP4 assembly
- [x] Offline narration via Windows Speech and optional local Piper
- [x] Per-run manifest and QA quarantine
- [x] Automatic uploading and scheduling disabled
- [ ] Validate a full render on the target laptop and tune render time
- [ ] Add more original character rigs and scene templates without external assets
- [ ] Improve narration timing and word-by-word caption synchronization
- [ ] Add a local, optional topic research stage only if it can work without paid APIs and preserves source/license checks

## Non-goals for the MVP

- Paid APIs, subscriptions, cloud GPU rental, or required accounts
- Downloading large AI video models onto the 4 GB RAM laptop
- Slideshow/photo-zoom fallbacks presented as 3D animation
- Automatic posting before a person reviews the rendered MP4
